# 钱潮 Money Tide Day 1 Launch Plan

## Goal

Launch a credible public MVP within one week: homepage, article pages, category pages, subscription page, basic CMS path, SEO/legal pages, and newsletter capture.

## Day 1 Scope

1. Confirm brand and visual direction.
2. Create PHP public routing scaffold.
3. Build guest homepage, article page, category page, latest page, subscription page.
4. Add initial Option 3-inspired UI theme.
5. Add Hostinger-ready `.htaccess`.
6. Add MySQL schema and seed categories.
7. Prepare next-day backlog for admin CMS and real newsletter storage.

## Week 1 Backlog

1. Connect pages to MySQL through PDO.
2. Create admin login.
3. Create article create/edit/publish screens.
4. Store newsletter subscribers in MySQL.
5. Add image upload for article hero images.
6. Add sitemap and robots.txt.
7. Add Open Graph metadata.
8. Add first 10 launch articles.
9. Add analytics snippet.
10. Deploy to Hostinger staging domain.

## Editorial Operating Rhythm

1. Morning: publish one daily briefing.
2. Afternoon: publish two short explainers.
3. Evening: prepare next-day AI-assisted article drafts.
4. Every article must include `一句话看懂`, `为什么重要`, source links, and investment disclaimer when relevant.
